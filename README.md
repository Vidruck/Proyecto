# Proyecto de Control de Acceso

Sistema de control de acceso web desarrollado con Spring Boot y Thymeleaf.

## Descripción
Este proyecto es una aplicación web para la gestión de citas, empleados y sucursales de una barbería/estética. Incluye funcionalidades de autenticación, gestión de usuarios, y reportes estadísticos.
